# 룬 사전 · 룬 대결

실제 룬 문자로 만든 판타지 룬 사전과, 룬을 조합해 친구와 겨루는 대결 게임이에요.
GitHub Pages에 올리면 누구나 링크로 열 수 있고, 휴대폰 홈 화면에 앱처럼 설치할 수 있어요.

| 파일 | 내용 |
|---|---|
| `index.html` | 룬 사전 (도감 기록은 각자 기기의 브라우저에 저장) |
| `duel.html` | 룬 대결 (친구와 대결은 Firebase, 컴퓨터와 연습은 설정 없이 바로) |
| `rules.html` | 룬 대결 규칙서 (캐릭터 소개 포함) |
| `duel/` | 룬 대결 그림 (캐릭터·배경·스킬 이펙트·영역 마법진)과 그림 목록 `assets.js` |
| `firebase-config.js` | **Firebase 설정값을 넣는 파일** |
| `firestore.rules` | Firebase에 붙여넣을 보안 규칙 |
| `manifest.webmanifest`, `sw.js`, 아이콘 | 앱 설치와 오프라인용 |

## 설정 순서

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 들어가요.
2. **프로젝트 만들기**(또는 프로젝트 추가) → 이름 입력 → Google 애널리틱스는 꺼도 돼요 → 만들기.

### 2. 웹 앱 등록하고 설정값 복사
1. 프로젝트 첫 화면에서 웹 아이콘 **`</>`** 을 눌러요.
2. 앱 닉네임(예: 룬 사전)을 넣고 **앱 등록**. "Firebase 호스팅"은 체크하지 않아요.
3. 화면에 나오는 `const firebaseConfig = { ... };` 부분을 복사해 둬요.
   (나중에 다시 보려면: 톱니바퀴 → 프로젝트 설정 → 내 앱 → SDK 설정 및 구성 → 구성)

### 3. 익명 로그인 켜기
왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법** 탭 → **익명** → 사용 설정 → 저장.
친구들은 가입이나 로그인 없이 자동으로 익명 계정을 받아요.

### 4. Firestore 데이터베이스 만들기
**빌드 → Firestore Database → 데이터베이스 만들기**
- 버전을 물어보면 **Standard**
- 위치는 **asia-northeast3 (서울)** 추천 (나중에 못 바꿔요)
- **프로덕션 모드**로 시작

### 5. 보안 규칙 붙여넣기
Firestore Database → **규칙** 탭 → 안에 있는 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여넣기 → **게시**.

### 6. 설정값 넣기
`firebase-config.js`를 열어 `const firebaseConfig = { ... };` 부분을 2번에서 복사한 내용으로 덮어써요.
이 값들은 사이트에 공개돼도 괜찮아요. 데이터는 5번의 보안 규칙이 지켜요.

### 7. GitHub에 올리기
1. https://github.com 로그인 → 오른쪽 위 **+ → New repository**
2. 이름(예: `rune`) 입력, **Public** 선택 → Create repository
3. **uploading an existing file** 링크 → 이 폴더의 파일을 **전부** 끌어다 놓기 → Commit changes
4. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
5. 1~2분 뒤 `https://내아이디.github.io/rune/` 에서 열려요.

설정값은 GitHub에 올린 뒤 `firebase-config.js`를 눌러 연필 아이콘으로 바로 고쳐도 돼요.

### 8. 앱으로 설치
- 안드로이드(크롬): 사이트를 열고 메뉴 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- 아이폰(사파리): 공유 버튼 → **홈 화면에 추가**

## 대결하는 법
방장이 **방 만들기**를 누르면 6자리 코드가 나와요. 친구에게 사이트 주소와 코드를 보내면, 친구는 **룬 대결**에서 코드를 넣고 입장하면 돼요.

혼자 시험해 볼 때는 한쪽을 **시크릿 창**(또는 다른 브라우저)으로 여세요. 같은 브라우저의 두 탭은 같은 사람으로 보여요.

## 문제가 생기면
룬 대결 첫 화면의 안내 문구가 원인을 알려줘요.

| 안내 문구 | 할 일 |
|---|---|
| firebase-config.js에 Firebase 설정값을 넣어야 해요 | 6번 |
| 익명 로그인이 꺼져 있어요 | 3번 |
| Firebase 설정값이 맞지 않아요 | 6번에서 복사한 값을 다시 확인 |
| Firestore 데이터베이스가 아직 없어요 | 4번 |
| 저장이 거부됐어요 | 5번 규칙을 게시했는지 확인 |

파일을 고쳐 올렸는데 예전 화면이 보이면, 한 번 새로고침하세요.
Firebase는 무료 요금제(Spark)로 충분하고, 결제 정보를 넣지 않으면 요금이 나오지 않아요.
